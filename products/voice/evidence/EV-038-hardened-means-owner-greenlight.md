"owner greenlight"

Resolves OQ-8. A rung is hardened when the owner says so — not when tests pass, not when a
checklist completes. Consequence: the gate between rungs is a review session in which he
exercises the thing himself (EV-005, EV-009), and with the bound waived (EV-030) this is the
bet's sole scope-control mechanism. Two obligations follow for the build: each rung must
arrive in a state he can actually drive without setup work, and no work on rung N+1 begins
before rung N is greenlit — starting ahead is precisely how console got composed all at once
(EV-029).
