The live site does nothing now: no events going, no real calendar, and the owner will not share its current state with anyone. Historical mode was per-event dedicated deployments (events.ronitnath.com) validated narrowly for one event each. The core pain: no self-serve path to create an event — "if I wanted to set up pickleball on August 15th, right now there's no path for that." Wanted first: a CMS-style interface to arbitrarily create, modify, and manage events, easy enough to share results with others. Calendar/circles/photos explicitly wait until that is easy.
