"The import flow is one time and mediated by the ai coding agent, not a full user flow."

Expressing the three past events' data in the new model (PKT-08) stays in the bet and stays acceptance-relevant — the expressibility test is unchanged. What is withdrawn is its *UI*: there are no import screens, no unmappable-field review surface, no owner journey through an importer. An agent runs it once, against a snapshot, and writes an import-notes file the owner reads as a file.

Generalized into the system as `flow-addendum.md` rule 2: one-time, machine-mediated work is a work packet, not a flow. Drawing it as a flow invents UI that will never be built — which is exactly what layer 3 of the design gate did (row E, five screens).
