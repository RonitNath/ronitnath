"audgent is pure internal. Rinity is external."

Settles the exposure boundary between the two planes: audgent never has a customer-facing
surface — no customer logs into it, no customer-visible branding, no external API sold from
it. Everything a customer sees, touches, or buys is rinity. Consequences: every
customer-relevant engine capability (call review, transcripts, agent behavior configuration)
must be re-surfaced through rinity's console; audgent's own UI (upstream dograh console,
EV-011/AC-02) is an operator tool at most. Sharpens EV-008: audgent is in design scope
precisely because rinity must project its capabilities outward.
