"Further, agents are the priamry interaction/interfacing surface."

Names the primary user: agents, not humans and not customer applications. audgent's first-class
interface is the one an agent worker drives — reading, authoring, running, and inspecting
voice work programmatically — with the human surface secondary (EV-004). Consequence: the
API/tool surface is the product, and it must be legible to an agent rather than merely
complete: the MCP authoring server, run readback, transcripts/artifacts, and evaluation
outputs stop being adjuncts to a console and become the design center. Existing machine-caller
plumbing (service principals, client-credentials auth, scopes, EV-011/AC-11) was built for
customer backend integrations; whether it fits agent callers is open. Ambiguity to resolve in
the interview: whether "agents" means the owner's dev/PM agents operating audgent, the voice
agents audgent runs, or both.
