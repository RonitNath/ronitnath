"there's a lot of cost because it's difficult for me to separate between what is natural production workflow versus what is just like the agents doing a bunch of testing for my behalf."

A live, money-denominated pain: agent test traffic and real production traffic are commingled
in the same cost surface, so spend can't be attributed and therefore can't be controlled. Two
demands fall out and should not be conflated — (a) **attribution**: every run is labelled
production or agent-test, and cost rolls up separately; (b) **containment**: the cheap path
for agent testing exists and is the default for it. Consequence: run provenance becomes a
first-class field, not a tag convention, and it's the join key for the cost view in EV-014.
Directly caused by EV-011 — giving agents a test verb makes this worse before it makes it
better.
