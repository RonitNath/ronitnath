"Agents diagnosing is yes."

Admits the fifth agent verb, which FLOWS-001 had listed as a named non-goal under EV-021.
Agents diagnose failures: they read runs, transcripts, costs and — given EV-026 — the wire-level
request/response record, programmatically, to work out why something failed. Consequence: the
agent surface is not only write-then-verify (EV-011); it is also read-to-investigate, which
means the diagnostic evidence added by EV-026 must be reachable by an agent and not only
rendered in a UI. Pairs with EV-026 as one capability with two consumers: the same record
serves the owner's drill-down and the agent's investigation, and building it for only one of
them is the predictable mistake.
